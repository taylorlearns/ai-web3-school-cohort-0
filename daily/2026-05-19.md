**核心收获：**

**Prompt**
- Prompt 是接口设计不是咒语，要把任务目标、输入边界、输出格式、失败处理写进可执行的沟通协议
- Instruction 四段拆开：任务目标 / 可用输入 / 禁止行为 / 输出格式
- Few-shot 要跟 eval 一起维护，协议升级后旧示例会误导模型
- 完整安全链路：Prompt → Context → Model → Code → Guard → Human

**Context**
- 模型只能基于它看见的上下文行动；系统决定什么能进上下文
- Context Engineering 目标不是塞满窗口，而是让模型在正确的信息层级里工作
- Memory ≠ 实时授权！过去允许的操作不代表现在仍然允许
- Agent 上下文分层：指令层 → 任务层 → 事实层 → 知识层 → 记忆层

**Network**
- 区块链核心是让互不信任的参与者对状态变化达成一致
- 区块三要素：顺序、gas limit、可验证历史链
- 测试网只能测流程，不能替代主网安全审查
- AI Agent 必须知道自己在哪条链上操作，工具应返回结构化网络信息
