## 笔记：助记词 → 私钥 完整推导路径

### 整体流程

```
助记词（12/24个单词）
    ↓ BIP-39 + 可选 passphrase
    ↓ PBKDF2 迭代 2048 轮
种子（512 bit）
    ↓ BIP-32（Hierarchical Deterministic Wallet）
    ↓ HMAC-SHA512
主私钥（256 bit）+ 链码（256 bit）
    ↓ BIP-44 推导路径 m/44'/60'/0'/0/0
目标链私钥
    ↓ 椭圆曲线 secp256k1
    ↓ Keccak-256 哈希（取后20字节）
以太坊地址
```

### 各步骤详解

#### 1️⃣ BIP-39：助记词 → 种子
- 助记词从 2048 个单词的词库中选取
- 通过 PBKDF2（Password-Based Key Derivation Function 2）进行 2048 轮迭代
- 可选的 passphrase 提供额外保护层：即使助记词泄露，没有 passphrase 也无法恢复种子

#### 2️⃣ BIP-32：种子 → 主私钥
- 分层确定性（HD）钱包的核心协议
- 一个种子可以派生出无限多个子密钥对
- 父私钥 + 链码 → 子私钥（单向不可逆推导）
- 推导路径 m / purpose' / coin_type' / account' / change / index

#### 3️⃣ BIP-44 推导路径
| 层级 | 含义 | 示例 |
|------|------|------|
| m | 主密钥 | — |
| 44' | BIP-44 协议标识 | 固定 |
| 60' | 币种（60 = Ethereum） | ETH / BSC / Polygon 共用 |
| 0' | 账户 0 | 第一个账户 |
| 0 | 外部链（接收地址） | 收费地址 |
| 0 | 索引 0 | 第一个地址 |

#### 4️⃣ 私钥 → 地址
- **secp256k1** 椭圆曲线：私钥 → 公钥（不可逆，离散对数难题保证安全性）
- **Keccak-256** 哈希：公钥 → 哈希值
- 取哈希后 20 字节 → **以太坊地址**

### 安全性要点
- 🔐 私钥的数学基础是椭圆曲线离散对数难题（ECDLP），以当前算力无法反推
- ⚠️ 助记词是加密资产的 **唯一主权凭证**，控制助记词 = 控制所有派生地址
- 🛡️ 使用 passphrase 增加一层保护（BIP-39 标准支持）
- 📝 推导路径标准化确保不同钱包间互操作性

---

**一句话总结：** 12个助记词通过 BIP-39/32/44 三层协议标准，结合 PBKDF2 密钥派生和 HMAC-SHA512 哈希函数，最终在椭圆曲线密码学（secp256k1）的保障下，派生出所有区块链上的私钥和地址。
