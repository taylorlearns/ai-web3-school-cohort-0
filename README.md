## 关于 AI × Web3 School

AI × Web3 School 是一个面向 builders 的开源学习计划，由 LXDAO 与 ETHPanda 共同发起。这里系统学习 AI、区块链、智能合约、AI Agent 与去中心化 AI，并通过 Bootcamp 和项目实践连接真实协作。

- **Handbook（中文）**：https://aiweb3.school/zh/handbook/
- **WCB 课程页面**：https://web3career.build/zh/programs/AI-Web3-School
- **WCB Learning**：https://web3career.build/zh/programs/AI-Web3-School#tab=learning
- **GitHub 仓库**：https://github.com/lxdao-official/aiweb3school
