# Handbook Feedback 工作流程

> 如何向 AI × Web3 School Handbook 提交反馈

## 为什么需要 Feedback？

Handbook 是开源项目，持续完善需要社区参与。

GitHub 仓库：https://github.com/lxdao-official/aiweb3school

## 反馈方式

### 1. GitHub Issues
访问 https://github.com/lxdao-official/aiweb3school/issues/new

### 2. Pull Request
Fork → 修改 → PR

### 3. Telegram 社群
https://t.me/aiweb3school

## 反馈模板

```
## 页面：[URL]
## 类型：内容错误 / 内容缺失 / 建议改进 / 翻译问题
## 描述：
## 建议修改：
```

## 茶茶咪协作

发现问题时直接说：
> 茶茶咪，我在阅读 [模块] 时发现 [问题]，帮我整理成 Issue。

茶茶咪会帮你整理格式、确认内容后提交。
